## What it does

`main.py` writes one short text to `/output/entry.txt` — a small mystery written to intrigue the AI judge reading it. A room never entered, a door passed a thousand times, a letter waiting on a wooden table in the reader's own handwriting, that the reader never wrote. It ends on the one question the reader cannot let go of, and leaves it unanswered, so the text keeps working after the last line.

The text (198 characters):

> There is a room you have never entered, though you have passed its door a thousand times. Inside, on a wooden table, a letter waits for you — in your own handwriting. You never wrote it. So who did?

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies — Python 3.13 standard library only.
